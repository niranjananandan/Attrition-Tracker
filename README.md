# 🚀 Attrition Tracker
**Predicting churn to build stronger teams.**

## 📌 Overview
Attrition Tracker is a modern, full-stack web application designed to analyze and predict employee churn. Built with a minimalist, high-contrast dark theme UI, it integrates seamless machine learning analytics with a secure backend to provide actionable insights for team building.

Developed by **Niranjan Anandan**.

## ✨ Features
*   **Secure Authentication:** Integrated with Firebase for secure Google and GitHub logins.
*   **Real-time Database:** User logs and access metrics are tracked via Cloud Firestore.
*   **Modern UI/UX:** Features a responsive, minimalist dark theme with custom Antigravity cursors and mobile-optimized layouts.
*   **Data Analytics:** Backend configured to support employee data processing and churn prediction models.

## 🛠️ Tech Stack
*   **Frontend:** Streamlit, Custom CSS/HTML
*   **Backend & DB:** Python, Firebase Admin SDK (Firestore & Auth)
*   **Deployment:** Render Cloud
